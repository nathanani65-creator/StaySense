# คู่มือการแบ่งภาพและนำไปใส่เล่มวิจัย

## 1. เหตุผลที่ต้องแบ่งภาพ

ภาพรวมทั้งระบบ (`staysense-workflow.png` ในโฟลเดอร์แม่) มีโหนดมากกว่า 100 จุด กว้าง/สูงหลายพันพิกเซล เหมาะสำหรับ
"ภาพที่ 3.1 ภาพรวมทั้งระบบ" เพียงภาพเดียวตามที่โจทย์กำหนด แต่ **ไม่เหมาะกับการอ่านละเอียดในหน้ากระดาษ A4** จึงตัดแบ่ง
ออกเป็นภาพย่อยอีก 7 ภาพ ตามกลุ่มการทำงานเดิมที่มีอยู่แล้วในแผนภาพ (ไม่ได้สร้างเนื้อหาใหม่ เพียงตัดแบ่งและใส่
"จุดเชื่อมข้ามภาพ" — เส้นประสีเทาแบบกล่อง มีลูกศร ↪ ไปยัง.../ ↩ มาจาก... กำกับ — เพื่อให้ผู้อ่านตามรอยลำดับการทำงาน
ข้ามภาพได้)

## 4. วิธี Capture/Export เป็นรูปภาพ

### วิธีที่ 1 — ใช้ไฟล์ PNG ที่ Render ไว้แล้ว (แนะนำ ง่ายที่สุด)
ไฟล์ `.png` ทุกไฟล์ในโฟลเดอร์นี้ถูก Render ด้วย `mermaid-cli` ที่ความละเอียด **3 เท่า** ของค่าเริ่มต้น (เทียบเท่า ~300 DPI
เมื่อพิมพ์ที่ความกว้างหน้า A4) คมชัดพอสำหรับพิมพ์เล่มวิจัยโดยตรง — นำไฟล์ไป Insert > Picture ใน Microsoft Word
หรือ `\includegraphics` ใน LaTeX ได้ทันที ไม่ต้อง Capture หน้าจอเอง

### วิธีที่ 2 — แก้ไขแผนภาพแล้ว Export ใหม่ด้วยตนเอง
หากต้องแก้ไขเนื้อหาภาพ (เช่น เปลี่ยนคำ เพิ่ม/ลดขั้นตอน) แก้ที่ไฟล์ `.mmd` ของภาพนั้น แล้วสั่ง Export ใหม่ด้วยคำสั่ง:
```
npx @mermaid-js/mermaid-cli -i fig-3.6-manage-accommodation-crud.mmd -o fig-3.6-manage-accommodation-crud.png -b white -s 3
```
เปลี่ยนชื่อไฟล์ตามภาพที่ต้องการ ค่า `-s 3` คือสเกล 3 เท่า ปรับเป็น `-s 4` ได้หากต้องการความคมชัดสูงขึ้น (ไฟล์จะใหญ่ขึ้นตาม)

### วิธีที่ 3 — ไม่มี Node.js ใช้เว็บ Mermaid Live Editor แทน
1. เปิด https://mermaid.live
2. คัดลอกเนื้อหาไฟล์ `.mmd` ที่ต้องการ วางในช่อง Code ทางซ้าย
3. เมนู Actions (ขวาบน) → PNG หรือ SVG
4. ก่อน Export ตั้งค่า Background เป็นสีขาว (ไม่ใช่โปร่งใส) เพื่อไม่ให้พื้นหลังเป็นสีดำเมื่อพิมพ์

### ไม่แนะนำ: การแคปหน้าจอ (Screenshot) โดยตรง
วิธีนี้ได้ความละเอียดต่ำ (ขึ้นกับความละเอียดหน้าจอ) ตัวอักษรอาจแตกเมื่อขยายในเล่มวิจัย ควรใช้เฉพาะกรณีฉุกเฉินที่ไม่มี
เครื่องมือ Export เท่านั้น

## 5. การใส่คำบรรยายใต้ภาพใน Word

ใช้ฟังก์ชัน `Insert > Caption` ของ Microsoft Word ตั้ง Label เป็น "ภาพที่" และเลขให้ตรงกับหมายเลขบทที่ 3 (เช่น 3.1, 3.2)
วิธีนี้ Word จะอัปเดตเลขภาพอัตโนมัติเมื่อมีการเพิ่ม/ลบภาพภายหลัง และสร้างสารบัญภาพ (List of Figures) ให้อัตโนมัติด้วย
